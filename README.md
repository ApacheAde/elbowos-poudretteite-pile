# Poudretteite Pile

Full-colour Python 3 neon slab-stack arcade for ElbowOS.

A glowing slab rides a rail. Drop it onto the tower. Overhang shears away. Perfect seats bloom. This is a timing stacker, not a tetromino well, and it is not a Nintendo ROM or emulator.

Featured account: https://x.com/ElbowOS

## Play

```bash
pip install -r requirements.txt
python3 poudretteite_pile.py --play
```

Space or Enter drops the slab. R restarts.

## Record a 9:16 reel

```bash
python3 poudretteite_pile.py --record
```

Writes a 15-second 1080x1920 H.264 MP4 (dummy SDL video driver, 30 fps).
